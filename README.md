# onService

이 문서는 현재 서비스 중이거나 완료된 프로젝트에 대한 정보를 제공합니다.

---

## 하이라이톡 (Highlightalk)

- **설명**:  
  카카오톡 대화를 통해 그룹 채팅방의 AI 분석을 제공하는 서비스입니다.  
  GPT 모델을 활용하여 채팅 내용을 분석하고 통계 자료를 사용자에게 제공합니다.  
- **상태**: ⏸️ (일시 중단) : Gpt-4o-mini 토큰 이슈
- **주소**: [하이라이톡 바로가기](https://highligh-talk-cghb.vercel.app/)  

---

## 솔직할지도 (FrankMap)

- **설명**:  
  지도 기반 감정 일기 서비스로, 사용자가 하루 동안의 감정을 기록하고 감정 데이터를 지도에서 확인할 수 있습니다.  
  날짜별 감정 통계를 제공하는 서비스 입니다.  
- **상태**: 🅾️ (운영 중)  
- **주소**: [솔직할지도 바로가기](https://frankmap.netlify.app/)  

---

## 위시 (WISH)

- **설명**:  
  난임 부부를 위한 AI 기반 심리 상담 서비스입니다.  
  사용자 맞춤형 심리 상담과 건강 데이터를 분석하여 종합적인 지원을 제공합니다.  
  서비스는 난임 문제로 어려움을 겪는 사용자들에게 정서적 안정과 실질적 도움을 목표로 하고 있습니다.  
- **상태**: 🅾️ (운영 중)  
- **주소**: [위시 바로가기](https://wish-test.netlify.app/home)
